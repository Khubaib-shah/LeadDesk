# LeadDesk Icon Slots

This folder is configured for animated Lottie JSON icons (from Icons8, Glyph Neue animated style).

### Supported Slots:
- `home.json` (Search: home)
- `leads.json` (Search: contacts)
- `pipeline.json` (Search: kanban)
- `followups.json` (Search: alarm)
- `analytics.json` (Search: bar chart)
- `add.json` (Search: plus)
- `user.json` (Search: user)
- `theme.json` (Search: sun)
- `help.json` (Search: help)
- `due-today.json` (Search: alarm / clock)
- `hot.json` (Search: fire)
- `won.json` (Search: trophy)

If an animated JSON file is not present in `/public/icons/SLOT.json`, the `AnimatedIcon` component seamlessly falls back to refined Lucide SVG icons with micro-interactions and motion physics.
Animated icons by [Icons8](https://icons8.com).
